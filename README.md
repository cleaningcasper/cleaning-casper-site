# Cleaning Services by Casper LLC

Static website for Cleaning Services by Casper LLC, a cleaning company based in Brownsville, TX that serves the entire Rio Grande Valley.

Plain HTML and CSS. There is no build step. The site is meant to be served by GitHub Pages from the root of the `main` branch.

Photos are free stock images under the Unsplash License, credited in `images/CREDITS.md`. Replace them with the owner's real photos using the same file names and aspect ratios.

Real photos are still to come. Never fill unknown facts in with guesses.
